# CrowdSimulation — LLM behaviour dataset for CrowdGym

Sub-project of the FYP *"Crowd Behaviour Modelling using LLM: Conflict Resolution"*.
Builds a dataset of **typical human behaviour in Singapore, organised by age and
gender**, generated by prompting the **DeepSeek API**, and shaped so it can be
consumed directly by the senior's **CrowdGym** simulation environment.

## Why this dataset exists (short version)

CrowdGym's rule-based models (Social Force / Collision-Free Speed) *deadlock* at
bottlenecks and, in the senior's own words, "cannot handle the situation as a
human would". Calling an LLM per agent per step is impossible at 10,000 agents.
So we query the LLM **offline**, once per `(scenario x age x gender)`, freeze the
answers into this dataset, and let the simulation do O(1) lookups at runtime.
See `integration/crowdgym_mapping.md` for exactly how records feed CrowdGym.

## How to get the token cost before running anything

```
pip install -r pipeline/requirements.txt
python pipeline/estimate_cost.py
```

It renders every prompt that *would* be sent, counts tokens (tiktoken if
available, else a documented heuristic), applies the rates in `config.py`, and
prints the projected spend plus a sensitivity table over `repeats` and pricing.
It exits non-zero if the projection exceeds the remaining budget, so it can gate
the generator later.

## Design decisions (need supervisor sign-off) vs assumptions

- **DD1** Generation unit is `(scenario x persona)`, *not* `(scenario x persona-pair)`.
  Pairwise conflict outcomes are composed later by the adapter from each persona's
  `yield_likelihood` + a small set of generic priority rules. This keeps cost linear.
- **DD2** Persona framing is *observer* ("describe how a 72-year-old woman in
  Singapore typically behaves"), not first-person role-play — lower stereotype risk.
- **DD3** The dataset is stored as language-neutral JSON/CSV. Only the thin Python
  adapter in `integration/` knows CrowdGym's API, so the in-progress C++ port only
  needs a new adapter, not a new dataset.
- **DD4** The LLM gives coarse/qualitative movement attributes; a documented,
  literature-anchored mapping turns them into CrowdGym's numeric AgentType params.
- **A1** DeepSeek pricing and Singapore population weights in the configs are
  *assumptions* — marked `VERIFY` in-file. Confirm before relying on them.
- **A2** tiktoken `cl100k_base` is used as a proxy for DeepSeek's tokenizer
  (typically within ~10-15%); the estimator inflates by a safety factor.
